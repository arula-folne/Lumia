LumiaMusicView — インストール手順（OBS Studio / Windows x64）
============================================================

【インストール（推奨：インストーラー）】
1. OBS Studio を終了する
2. LumiaMusicView-*-windows-x64.exe を実行する
3. 案内に従い、OBS のインストールフォルダを確認する
   （通常は C:\Program Files\obs-studio）
4. インストール完了後、OBS を起動する
5. ソース → 追加 → LumiaMusicView

管理者権限の許可を求められた場合は許可してください。


【手動インストール（zip など）】
OBS フォルダへ次の配置になるよう展開してください。

  obs-studio\obs-plugins\64bit\lumia-music-view.dll
  obs-studio\data\obs-plugins\lumia-music-view\...


【アンインストール】
1. OBS を終了する
2. Windows の「アプリと機能」から LumiaMusicView を削除する
   または次を手動削除:
     obs-plugins\64bit\lumia-music-view.dll
     data\obs-plugins\lumia-music-view\
